# Planarian Project Execution

Planarian is an AI website clone orchestrator for repeatable, file-based UI reconstruction workflows.

Phase 1 creates the foundation only: a pnpm monorepo, shared CloneSession types, target analysis with Playwright, best-effort site classification, session file generation, agent-memory files, minimal integration stubs, and validation scripts.

Planarian does not bypass authentication, paywalls, private APIs, private data, or backend systems. It clones visible public UI structure and uses mock data or placeholder routes for private, dynamic, authenticated, payment, trading, database, or user-data behavior.
